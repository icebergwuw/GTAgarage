# GTA Garage

用官方 GTA V 暂停菜单地图管理 GTA Online 个人载具库存。

- 背景是 Rockstar Social Club 的 San Andreas 地图瓦片
- 默认地图只显示**已拥有**的房产，避免把全部候选点一次铺开
- 同一栋楼（如 Eclipse Towers 的 8 套公寓）地图上只显示一个点，点进去再选具体单位，每套各占 1 个公寓名额
- 购买房产按 GTA Online 上限：公寓和独立车库合计 10 处；办公室、夜总会、事务所、改装店、会所、机库、街机厅、保释所各 1 处；豪宅可买齐 3 处；Eclipse Blvd / Vinewood Club / Arena / 赌场顶层 / 制衣厂可同时拥有
- 同类满员时需下架或置换，车库里还有车就不能卖
- 悬停车库看容量、估值和车头图；点击进入库存
- 车辆图和资料来自 FiveM / GTA Wiki
- 本地可增删改、跨车库移动，数据存在浏览器里

不含地堡、设施、货物仓、载具仓库、游艇、潜艇、拆车场、洗车店和 McKenzie 机库（那些不是常规个人载具库存）。

```bash
npm install
npm run dev
```

打开终端提示的本地地址。示例车队可以整份替换成你自己的库存；右上角可导出 JSON。

## 项目验证准则

- 每次修改交互后，必须运行 `npm run build`，并针对改动路径做实际操作回归。
- 每次修改完成后，必须提供一个可操作的本地预览地址，并说明从哪里进入改动。
- 推送线上前，必须先确认本地预览通过；线上部署后还要提供线上地址和部署状态。
- 每次涉及较大改动，必须先保存可回滚补丁到 `/tmp/`，并在交付说明中提供路径。
- 未经确认不得直接推送线上；构建失败或关键交互未验证时不得宣称完成。
